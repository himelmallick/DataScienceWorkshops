# DataScienceWorkshops

This repository contains teaching materials for data science workshops and short courses offered by the Mallick Lab at Cornell University.

A subset of the materials is hosted [here](https://github.com/omicsEye/Workshop). An up-to-date list of talks and short courses is on [my website](https://www.himelmallick.org/talks/).
